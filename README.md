# WebAR 浸水深シミュレーション v2.6 多言語版

## 概要

この版は **マーカーなし正式版 v2.5** を多言語化したものです。

過去に成功している **getUserMedia 直接カメラ表示方式** を維持し、MindAR / AR.js / Three.js を使わずに、スマホカメラ映像へ浸水表現を重ねます。

## 対応言語

- 日本語
- やさしい日本語
- English
- 中文
- 한국어

## v2.6 の特徴

- マーカーなし
- 外部ライブラリなし
- `index.html` 1ファイルで動作
- getUserMediaでカメラ映像を直接表示
- 多言語切り替え
- 水面ライン
- 水面下の水色半透明フィルター
- 波の揺れ
- 水の濃さ調整
- 波の強さ調整
- 水面高さの手動調整
- 体験開始ボタン
- 操作パネル非表示
- 右下の「操作」ボタンで復帰

## GitHub Pagesへのアップロード

1. GitHub Desktopで対象リポジトリを開く
2. 既存の `index.html` をこの版の `index.html` で上書き
3. `README.md` をこの版の `README.md` で上書き
4. Summary に以下を入力

```text
Add multilingual support v2.6
```

5. `Commit to main`
6. `Push origin`

## スマホでの確認URL

```text
https://marunonbe.github.io/webar-flood-stable-test/?v=26
```

## 確認手順

1. ChromeまたはSafariで開く
2. 言語を選ぶ
3. 「カメラ開始」を押す
4. カメラを許可する
5. カメラ映像が表示されることを確認
6. 水面↑ / 水面↓ / スライダーで水面位置を合わせる
7. 必要に応じて水の濃さ・波の強さを調整
8. 「この高さに固定」を押す
9. 「体験開始」を押す
10. 右下の「操作」でパネルを戻す

## 黒画面の場合

- GitHub PagesのHTTPS URLで開いているか
- カメラ許可を拒否していないか
- 端末のカメラが他アプリで使われていないか
- URL末尾に `?v=26` を付けて再読み込みしたか
- SafariでだめならChromeで試したか
